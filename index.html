Estimating personality from a facial photo

Your photo is compared with composite faces that average people scoring high and low on each Big Five trait, taken from Little & Perrett (2007). A face-recognition model (FaceNet-512) decides which composite of each pair your face sits closer to.

Read this first

This app is intended strictly for experimental and educational purposes. It does not provide a valid, reliable, or scientifically endorsed method for inferring personality traits from facial images. Personality is a complex, multi-dimensional construct that cannot be accurately assessed from appearance alone. Any apparent patterns or outputs should be interpreted as illustrative artifacts of the dataset and method, not as diagnostic or predictive insights. Use responsibly and with critical awareness of ethical and scientific limitations.

3Develop

Add a photo and pick a composite set first.

4The proof sheet

Each row is one trait. The bar shows the gap in cosine similarity between your face and the two composites: it points toward the composite your face is closer to. The gap is the only hint about how strong the evidence is, and all rows share one scale.

These labels describe which blurry average face a neural network finds more similar to yours. They are not a personality assessment.

How it works

  1. Find the face. A face detector locates the face, rotates it so the eyes are level, and crops it.
  2. Embed it. FaceNet-512, the same model the original Python script uses through the DeepFace library, turns the crop into a vector of 512 numbers.
  3. Compare. The same is done for the composite faces. For each trait, cosine similarity to the "high" and "low" composite is computed, and the higher one wins.

Everything runs locally in your browser; the model (about 45 MB) is downloaded once and then cached. This is a browser port of the original Python script by Luděk Stehlík. It uses a different face detector than the script, so numbers can differ slightly.

Composite images: Little, A. C., & Perrett, D. I. (2007). Using composite images to assess accuracy in personality attribution to faces. British Journal of Psychology, 98(1), 111–126.
